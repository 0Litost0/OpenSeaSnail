# Audio fixture attribution and licenses

## Procedural business-test audio

`audio/pipeline-v1.wav` is generated by SeaSnail's `scripts/generate_audio.py`
using integer triangle-wave PCM. It contains no speech, recordings or external
samples and is covered by the project's Apache-2.0 license. It tests upload,
normalization and storage with a deterministic ASR fixture, not speech accuracy.

## FLEURS speech fixtures — CC BY 4.0

`audio/fleurs-zh-v1.wav` and `audio/fleurs-en-v1.wav` contain full utterances from
**FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech**

Siddharth Dalmia, Jason Riesa, Clara Rivera and Ankur Bapna; Google Research and

The historical PoC uses the same English fixture via `poc/data/speech.json`;
it does not ship an additional system-voice recording. The old Apple-generated
WAVs are absent from this source snapshot.

## Reproduction

Tests consume committed WAVs and never invoke a speech service. To reproduce
fixtures, obtain the original two WAVs listed in `audio-provenance.json` from
the pinned official archives and place them in a local directory as
`zh-original.wav` and `en-original.wav`. Archive URLs and upstream LFS hashes
are recorded; independently verify complete archives when downloading them.
The generation command verifies each extracted source WAV's exact hash before
using FFmpeg. The initial acquisition streamed archive members rather than
verifying whole archives; this limit is recorded explicitly in the provenance.

```sh
python3 tests/api_regression/scripts/generate_audio.py --source-dir /path/to/fleurs-originals --check
```

Pass `--ffmpeg /path/to/ffmpeg` if needed. The command compares generated bytes
to pinned outputs; it does not rewrite references, manifests or quality limits.
Regeneration with a different converter that changes bytes must be reviewed.
