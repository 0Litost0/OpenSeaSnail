# API 回归框架 PoC

> 2026-10-02：用户已授权执行方案验证；本目录是选型实验，不代表正式设计或完整验收。

## 预先确定的比较标准

第一阶段用 Playwright、Vitest、Rust 测试体系执行相同业务：账户初始化 → dictionary 增改删查 → 退出旧进程 → 新进程读取 → 故意断言失败 → 独立重跑。共用 Rust 测试宿主和产品实现，不以框架安装顺序或复用前一个实验的环境适配作为优势。

硬条件：真实 HTTP、独立数据/凭据、真实进程重启、失败非零退出、用例可筛选、预期/实际差异可读、证据不泄漏凭据、资源回收。比较用例代码、步骤报告、结构化输出、重复执行和新增适配量。没有执行的能力明确列为未验证。

第二阶段对领先候选验证 multipart/异步任务、可控 clean 成功/错误/超时、真实 Sherpa、缺依赖、异常退出和重试。真实 Sherpa 的 PoC 样例断言仅验证机制，不作为正式质量阈值。

## 边界

- 独立 Cargo workspace 与 Node package；不改变产品构建或发布路径。
- 测试宿主复用生产 router、鉴权、业务服务、加密存储；测试凭据只保存于本次临时目录，不接触系统 Keychain。
- PoC 宿主尚不是生产启动组合根；明确记录此差异，不以其成功证明发行包安全与启动行为。
- 不自动调用付费 provider，不启动 UI，不自动修改预期消除失败。
- 原始运行产物忽略版本控制；提交脱敏结果记录及可复现代码。
