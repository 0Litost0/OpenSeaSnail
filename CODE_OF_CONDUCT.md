# Community code of conduct

Treat everyone with respect. Welcome questions, critique ideas with evidence, and give actionable feedback. Respect different backgrounds, experience levels, and communication styles.

Harassment, threats, discrimination, sexualized conduct, impersonation, and publishing private information without consent are not acceptable. Do not upload other people's recordings, transcripts, clipboard contents, or credentials.

Maintainers may edit or remove harmful content, close discussions, or restrict participation to protect the community. Apply the same expectations in issues, pull requests, and other project spaces.

For a private conduct concern, use a private maintainer contact when available. If none is published, request a private contact without posting identities or incident details publicly. A designated private conduct contact should be set before accepting community participation.
